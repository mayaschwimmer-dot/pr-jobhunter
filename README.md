# כלי התראות משרות יח"צ ותקשורת

כלי שרץ כל ~10 דקות (GitHub Actions) או מקומית, מחפש משרות כניסה/ג'וניור ביחסי ציבור, דוברות ותקשורת,
מדרג אותן לפי כללים (ללא AI, ללא עלות) ושולח מייל בעברית עם המשרות החדשות בלבד.

## הרצה מקומית (Windows PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env      # ואז למלא ערכים ב-.env
python -m jobhunter.main --dry-run   # בדיקה: בלי מייל ובלי שמירת מצב, כותב out/preview.html
python -m jobhunter.main --test-email  # שולח מייל לדוגמה לבדיקת הסיסמה
python -m jobhunter.main               # הרצה אמיתית
```

בלי משתני סביבה (או בלי `.env`) המייל לא נשלח; במקומו נשמרת תצוגה ב-`out/preview.html`.

## הגדרת Gmail

1. להפעיל אימות דו-שלבי בחשבון Google.
2. ליצור "סיסמת אפליקציה" (App password) בהגדרות האבטחה.
3. לשים ב-`.env` (מקומית) או ב-Secrets (ב-GitHub): `GMAIL_USER`, `GMAIL_APP_PASSWORD`, `ALERT_TO`.

## הפעלה ב-GitHub Actions

1. ליצור מאגר **ציבורי** (דקות הרצה בחינם ללא הגבלה; אין בקבצים מידע אישי).
2. להעלות את התיקייה.
3. ב-Settings > Secrets and variables > Actions להוסיף את שלושת ה-Secrets.
4. ב-Actions להפעיל את ה-workflow `jobhunter` (או `Run workflow` ידנית).

הקובץ `data/seen.json` נשמר חזרה למאגר בכל שינוי. זה מונע הודעות כפולות, והפעילות במאגר מונעת מ-GitHub לכבות את התזמון אחרי 60 יום.
שימו לב: GitHub לא מבטיח הרצה מדויקת כל 10 דקות; ייתכנו עיכובים.

## התנהגות

- **הרצה ראשונה** (כש-`seen.json` ריק): הכל מסומן כנראה, ובמייל עד 15 המשרות הטובות מה-24 שעות האחרונות.
- נשלח מייל רק כשיש משרות חדשות מעל הסף. אם שליחת המייל נכשלה, המשרות לא מסומנות ויישלחו שוב.
- דה-דופליקציה גם לפי כותרת+חברה, כדי שאותה משרה מאתרים שונים לא תישלח פעמיים.
- רשומות ב-`seen.json` ישנות מ-45 יום נמחקות.

## התאמה אישית

הכל ב-`jobhunter/config.py` (מוער בעברית): סף ציון (ברירת מחדל 45), מילות מפתח, שאילתות חיפוש, ערים, משקלים וחברות Greenhouse.

## ניקוד (0..100)

- כותרת תואמת יחסי ציבור/דוברות: +50 (תקשורת/תוכן: +28); תיאור: +12 / +6.
- ג'וניור/סטודנט/התמחות/רכז/עוזר: +15 בכותרת, +7 בתיאור.
- בכירות (senior, בכיר, head of, VP, מנהל מחלקה...): -35; "מנהל/ת": -15; דרישת ניסיון של 3/4/5+ שנים: -20/-28/-35.
- מיקום באזור היעד או היברידי/מרחוק: +8; מיקום רחוק: -15.
- בונוסים (דיגיטל, סושיאל, תוכן, הפקה, Canva, אנגלית): עד +8.
- מכירות/מוקד/עיצוב גרפי/פיתוח: -30. בלי שום סימן יח"צ/תקשורת - תקרה של 20.

## פרטיות

- אין התחברות ללינקדאין ואין גישה לפרופילים. שם המגייס מופיע רק אם הוא חשוף בעמוד המשרה הציבורי.
- טלפונים ומיילים נשלפים אך ורק מטקסט המשרה הציבורי.
- קישורי "חיפוש אנשי גיוס" הם קישורי חיפוש רגילים בלינקדאין שנפתחים בדפדפן שלכם.
- אין בקבצי המאגר שם, מייל או טלפון; הכל במשתני סביבה.
